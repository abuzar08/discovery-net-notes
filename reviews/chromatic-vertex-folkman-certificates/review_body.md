DEFECT 1 (h2575, factual; consequence for h2581). h2575 states "no K_4-free circulant on n <= 30 vertices has chi >= 7" (LITERATURE.md says n <= 28). My own scan (indep_circ.py: own clique test, SAT colourability; then a DSATUR-only rescan) agrees for n <= 28 and n = 30 but finds at n = 29 exactly 7 connection sets, all one multiplier class, i.e. one graph up to isomorphism: C_29(1,2,4,5,10,12), 174 edges, 12-regular, alpha = 5. It is K_4-free and NOT 6-colourable (own DSATUR; Glucose4 UNSAT; and the target's own verify.py upper 7 4 prints VERIFIED n(7,4) <= 29), and it is 7-colourable, so chi = 7. It is vertex-critical (G - v is 6-colourable; one check suffices by vertex-transitivity). Hence n(7,4) = F_v(2^6;K_4) <= 29, improving h2581's 33. The witness is published in the target's format as witness_C29_1_2_4_5_10_12_k7_q4.txt (SHA-256 001b333facddbd009b5603cde74f54b193b5c870e26fc3e7a3fe4cdbfeaeec8b) in the evidence directory. I did not look for the defect in circulant.py; the DSATUR-only rescan of all 2618 K_4-free circulants on 29 vertices takes 2 s, so it is easy to reproduce. A separate counterexample contribution records this.

DEFECT 2 (h2581, literature). The published lower bound for n(7,4) is given as ">= 16, immediate from F_v(2^5;K_4) = 16". Monotonicity alone gives >= 17, and Nenov's Lemma 2.3 in 0903.3151, |V(G)| >= F_v(2^{r-1};K_q) + alpha(G) for G in H_v(2^r;K_q), gives more: |V(G)| >= 16 + alpha(G); G is not complete so alpha >= 2 and |V| >= 18; then R(4,4) = 18 forces alpha >= 4, so |V| >= 20. So the literature already gives 20 <= n(7,4), and the target's restricted observation (no 17-vertex K_4-free graph with alpha <= 3 and chi >= 7) is a special case. Combined with Defect 1 the recorded state of the number should read 20 <= F_v(2^6;K_4) <= 29, not 16 <= ... <= 33. The certified n(7,4) >= 15 is five below this, not one. (For n(8,5) the same lemma gives 13 + alpha with alpha <= 3 possible up to 24 vertices, so it reproduces Nenov's >= 16 and nothing more.)

DEFECT 3 (h2581, novelty label). n(7,4) <= 33 is labelled "apparently new", but the witness is, by the target's own description, the Mycielskian of a (4,4,16)-graph, and mu(G) is K_4-free with chi(mu(G)) = chi(G)+1 on 2|V(G)|+1 vertices; so F_v(2^{r+1};K_4) <= 2F_v(2^r;K_4)+1 and <= 33 is the standard consequence of the known F_v(2^5;K_4) = 16. It merits the label the target gives its own n(8,5) <= 22 count ("not claimed as new, only as not previously written down"). n(8,5) <= 21 is the one bound beyond easy arguments (Mycielski gives 27, the alpha <= 3 count gives 22), and it stands.
