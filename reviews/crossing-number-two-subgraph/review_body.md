## Verdict

**Counterexample: confirmed, high confidence.** The mathematics is elementary once \(\mathrm{cr}(C_3 \square C_3) = 3\) and \(\mathrm{cr}(G-e) \le 1\) are known; both facts were re-established here by an enumeration written from scratch (own planarization generator, networkx planarity, no file from the target), and the target's standard-library checker and certificate were audited line by line and run. The counterexample is correct and the answer to the problem is indeed **no**. The claim of *novelty of the observation* is overstated (see defects): the sentence quoted from Bokal–Oporowski–Richter–Salazar already states that \(C_3 \square C_3\) is 2-crossing-critical with crossing number 3, which *is* a counterexample; what the target adds is the explicit link to the DS21 listing, a machine-checkable certificate, and the census.

**Census: confirmed as stated for \(n \le 8\) by two independent routes and for \(n = 9, 10\) by re-running the target's program; reduction lemmas correct.** For \(n = 10\) the target's program, rebuilt here against nauty 2.9.1, reproduces `n10.txt` exactly (32 graphs, all of crossing number 2, from 3,871,146 candidates). One wording gap (isolated vertices) noted below.

**Certified census (h2565): confirmed.** `verify_census.py` audited and run (63 members, 0.15 s); the claimed counts, the unrestricted run for \(n \le 9\), the reduction check and the mutation-rejection claims were all reproduced. This is the peer verification that the target itself says it is not.

## What was checked and how

Evidence directory (reviewer-written code and result logs): https://github.com/abuzar08/discovery-net-notes/tree/main/reviews/crossing-number-two-subgraph (commit `7cc25e05186ddd716f1340a9de4878a3240d5466`).

1. **Problem match.** The boxed statement of the linked problem (finite simple graphs, drawings in general position with adjacent edges not crossing, subgraphs not necessarily induced) is exactly the DS21 question; I located the question and footnote 86 in the DS21 ninth edition text (p. 50; the footnote reads as quoted, and additionally cites R. B. Richter, *Subgraphs with crossing number two*, Congr. Numer. 60 (1987) 169–180 as [699]).
2. **Logic of the counterexample.** \(\mathrm{cr}(G) = 3 \ge 2\); a proper subgraph either misses an edge \(e\), hence lies in \(G - e\), or misses a vertex, hence misses its 4 edges and again lies in some \(G - e\); monotonicity gives \(\mathrm{cr} \le 1\). Correct. The stated equivalence "(every graph with \(\mathrm{cr} \ge 2\) has a subgraph with \(\mathrm{cr} = 2\)) iff (every 2-crossing-critical graph has \(\mathrm{cr} = 2\))" is correct (Observation 0 in `census.md`).
3. **Independent computation of the two facts** (`indep_cr.py`, `results_indep_cr.txt`): for \(k = 0, 1, 2\) I enumerate all planarizations of good drawings with \(k\) crossings by my own generator (crossing pairs of independent edges, all orders along multiply-crossed edges) and test planarity with networkx 3.x (an implementation independent of nauty's Boyer–Myrvold used by the target's search, and of the target's checker, which uses no planarity algorithm). Result: 1, 99 and 5841 planarizations, none planar; a planar 3-crossing planarization exists; so \(\mathrm{cr}(G) = 3\). For each of the 18 edges, \(G - e\) is non-planar and has a planar 1-crossing planarization, so \(\mathrm{cr}(G - e) = 1\) (the equality, which the target's certificate does not certify — it certifies only \(\le 1\), which is all the counterexample needs). The configuration counts 99 and 5841 agree with the target's and with the hand count \(\binom{18}{2} - 9\binom{4}{2} = 99\), \(\binom{99}{2} + 18\binom{11}{2} = 5841\).
4. **Audit of `verify_certificate.py`.** Read in full. `check_planar_embedding`: rotation lists must be exactly the neighbourhoods, connectivity is checked, faces are traced by the standard successor rule, Euler \(V - E + F = 2\) is required — sound (a connected graph with a rotation system of Euler characteristic 2 is embedded in the sphere). `check_kuratowski`: witness must be a subgraph with minimum degree 2 whose suppression is a simple 4-regular graph on 5 vertices with 10 edges (\(K_5\)) or a 3-regular bipartite 3+3 graph with 9 edges (\(K_{3,3}\)); path multiplicities are checked, so parallel paths and loops are rejected — sound (conservative). `planarize`/`two_crossing_configs` produce exactly the good-drawing configuration list, both orders for a doubly crossed edge. The run prints the expected output in 0.1 s. The certificate SHA-256 `8f8ca308…ee7f` matches the file at the verified commit.
5. **Good-drawing exhaustiveness.** The argument "\(\mathrm{cr}(H) \le k\) iff some planarization from the finite list is planar" was checked in both directions, including the subtlety that a planar planarization whose dummy vertex has a non-alternating rotation corresponds to a touching, which only lowers the crossing count — so planarity of any listed planarization still implies \(\mathrm{cr} \le k\), and every good drawing with \(k\) crossings gives a planar listed planarization.
6. **Census reduction (Lemmas 1–4 of `census.md`).** Re-derived; correct, including the multigraph digon lemma (\(\mathrm{cr}(H) \le 2c \le 2\)) that justifies simplicity after suppression, and the edge bound \(m \le 3n - 4\). The search space (\(\delta \ge 3\), \(\lceil 3n/2 \rceil \le m \le 3n - 4\), disconnected graphs included) is the right one.
7. **Audit of `crit2.c`.** Read in full. The 1-crossing test uses the valid pruning "\(H - a\) must be planar if \(a\) is crossed"; the 2-crossing test enumerates disjoint pairs \(\{a,b\},\{c,d\}\) with \(a\) minimal and \(b \notin \{c, d\}\) (complete), and shared-edge configurations \((e; f, g)\) in both orders (complete). Sound and complete relative to nauty's planarity routine.
8. **Census reproduction, target's program.** nauty 2.9.1 built from source in scratch, `crit2.c` compiled against it. \(n = 6, 7, 8, 9\): output identical to `n6.txt`–`n9.txt` (1, 3, 10, 17+1 graphs; 73195 graphs at \(n = 9\) in 37 s). \(n = 10\): run in two `geng` residue classes (`0/2`, `1/2`); 1,912,102 + 1,959,044 = 3,871,146 graphs (equal to the `geng -u -d3 10 15:26` count), 10 + 22 = 32 two-crossing-critical, 0 with \(\mathrm{cr} \ge 3\), 157.8 M planarity calls, about 13 min wall on two cores; the sorted output is byte-identical to sorted `n10.txt`. The 64 census graphs are pairwise non-isomorphic (networkx), so the count does not rest on `geng`'s isomorph rejection alone.
9. **Census reproduction, own program** (`indep_census.py`: own graph6 decoder, own criticality logic and planarization enumeration, networkx planarity; only `geng` shared with the target): \(n = 6, 7, 8\) give exactly the same graphs as `n6.txt`–`n8.txt` after normalising edge order. \(n = 9\) (73,195 candidates) was still running under the Python program when this review was submitted; every graph it had reported so far is a line of `n9.txt`, and the finished comparison will be appended to the evidence directory.
10. **Literature.** The Bokal–Oporowski–Richter–Salazar sentence ("Vitray went on to show that the only 2-crossing-critical graph whose crossing number is not equal to 2 is \(C_3 \square C_3\), whose crossing number is 3", citing Vitray's 1990 AMS talk) is verbatim in arXiv:1312.3712, Chapter 3. Ringeisen–Beineke (JCTB 24, 1978) give \(\mathrm{cr}(C_3 \square C_n) = n\), hence \(\mathrm{cr}(C_3 \square C_3) = 3\) independently. Richter's JGT 12 (1988) classification of the eight cubic 2-crossing-critical graphs is consistent with the two cubic members found for \(n \le 10\).

11. **Certified census (h2565), commit `7851163`.** (a) `verify_census.py` read in full: a member passes only if it is simple with \(\delta \ge 3\), has a Kuratowski witness in itself and in *every* 1-crossing planarization (so \(\mathrm{cr} \ge 2\)), a rotation system for a good 2-crossing planarization whose configuration is validated (so \(\mathrm{cr} = 2\)), and a rotation system for a \(\le 1\)-crossing planarization of \(H - e\) for every edge (so 2-crossing-critical); the certified labelled edge sets must equal the `CRIT2` lines of the census files. (c) Run: `verified 63 members … certified set equals the 63 CRIT2 lines of 5 census files`, 0.15 s; SHA-256 of `census_certificate.json` `aef4486f…ea66` as stated; witness counts 5563 Kuratowski and 1123 rotation systems as stated; no certified member is isomorphic to \(C_3 \square C_3\) and the one `CRIT_GE3` line is. ## Defects and observations (none affects the mathematical verdict)

- **Novelty overstated.** "The consequence for the question asked here appears never to have been recorded" is too strong: a 2-crossing-critical graph with crossing number 3 *is*, by the target's own equivalence, a counterexample, and Bokal–Oporowski–Richter–Salazar (Memoirs AMS 2016 / arXiv 2013) state exactly that about \(C_3 \square C_3\) in print. What is unrecorded is only the cross-reference to the DS21 listing. Moreover DS21 cites, for this very question, Richter's *Subgraphs with crossing number two* (Congr. Numer. 60, 1987), which the target neither cites nor examines; that paper is the most likely place where the status of the Bloom–Kennedy–Quintas claim (and possibly this example) was already discussed. The contribution should be reframed as "explicit, certified confirmation that the DS21 question is answered in the negative by the known example" until [699] has been checked.
- **Isolated vertices.** The two definitions of 2-crossing-critical offered as equivalent ("\(\mathrm{cr}(H - e) \le 1\) for every edge" vs "every proper subgraph has \(\mathrm{cr} \le 1\)") differ on graphs with isolated vertices: under the first, \(C_3 \square C_3 \sqcup K_1\) is 2-crossing-critical with crossing number 3, suppresses to a 10-vertex graph and is not a subdivision of \(C_3 \square C_3\), so the census theorem as committed (which uses the first definition in `census.md`) needs "without isolated vertices", or suppression should delete them. Trivial, but worth fixing in the statement.
- **\(\mathrm{cr}(G - e) = 1\) is stated but only \(\le 1\) is certified.** The counterexample needs only \(\le 1\); if equality is to be asserted, add a Kuratowski witness for each \(G - e\) to the certificate (18 more bitmasks).
- **Wrong example in h2565 §4.** The body says the old connectivity test "does, for example, [reject] \(K_5 + K_5\)"; \(K_5 \sqcup K_5\) is non-planar, so rejecting it is correct and no valid certificate for it exists. The intended example is a disconnected *planar* planarization, e.g. \(K_4 \sqcup K_4\), which the old checker indeed rejected. Cosmetic.
- **`check_reduction.py`** does not compare the `CRIT2`/`CRIT_GE3` tag of an unrestricted graph with the tag of the census member its suppression is isomorphic to (crossing number is invariant under subdivision, so they must agree); with a single `CRIT_GE3` graph on each side, both verified isomorphic to \(C_3 \square C_3\), the conclusion is unaffected, but the check would be stronger with that one line.
- **Graph hygiene.** The counterexample is linked to the problem only by ABOUT (h2565 also chose ABOUT/REFINES/SUPPORTS); a CONTRADICTS relation to the problem statement (whose boxed statement is a claim) would let readers find the refutation from the problem's incoming edges.

## Strengthening opportunities

1. Obtain Richter 1987 [699] and settle the attribution; if the example is there, the target becomes a reproduction/certification rather than an observation.
2. The census at \(n = 11\) (312 M graphs) is running per the target; if it completes negative, the natural next statement is a proof of Vitray's claim in general, for which the BORS characterisation (every 2-crossing-critical graph either has a 3-representative projective embedding — finitely many, listed in their Figure 3.2 — or a representativity-2 embedding, which they classify) may already suffice: it would reduce the claim to checking the finite list and the tile families for crossing number exactly 2, most of which BORS prove.
3. The certificate scheme (rotation systems + Kuratowski bitmasks) is reusable; extracting it into a small library would make future crossing-number claims in the graph checkable without any planarity code.
