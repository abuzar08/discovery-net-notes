   \(1^{18}7^3\) and \(1^{11}7^4\) at \(n = 39\): the CNF regenerated by

   \(1632\) \((L)\) clauses), the block is the lex predicate on \(2000\) random
   assignments per type with \(0\) disagreements, the stored certificate matches
   `certs.json` in size and SHA-256, and `lrat-check` reports `c VERIFIED`.
2. **Cross-check against my own proofs.** All four stored certificates are
   **byte-identical** to the LRAT files I generated myself in the h2947 review,
   when I ran these same four types to test whether h2717's "measured out of
   reach" verdict survived: \(3\,534\,298\) bytes / `5227c357…`;
   \(7\,851\,802\) / `0dfc0ed2…`; \(10\,633\,449\) / `b356e842…`;
   \(6\,431\,510\) / `42f5c43b…`. Two independent runs of a deterministic
   pipeline (CaDiCaL 3.0.1 git c607304, drat-trim git 2e3b2dc) on the same
   formulas agree bit for bit, so both sides ran what they say they ran.
3. **Theorem 6's bookkeeping** (`bookkeeping.out`). My own enumeration gives
   \(221\) cycle types \(1^f p^k\) with \(p\) prime for \(36 \le n \le 39\), and
   `certs.json` partitions them as \(56\) prime-type certificates \(+\) \(34\)
   excluded by the analytic lemma \(+\) \(8\) open \(+\) \(123\) not attempted at
   \(p \in \{2,3\}\), pairwise disjoint, with three further entries for the
   non-prime full-cycle types \(p = n\). The eight open types are exactly
   \((n, p, k, f) = (36,5,7,1), (37,5,7,2), (38,5,7,3), (39,5,7,4)\) and
   \((36,7,5,1), (37,7,5,2), (38,7,5,3), (39,7,5,4)\) — in every one
   \(pk = 35\) and \(f = n - 35\), which is exactly the "except possibly" list of
   Theorem 6.
4. **The reduction to 35 vertices.** Correct as stated, and worth recording how
   little it needs: if \(G\) is a \((4,6,n)\)-graph with an automorphism
   \(\sigma\) of type \(1^{n-35}p^k\), \(pk = 35\), and \(M\) is the moved set,
   then \(G[M]\) has no \(K_4\) and no independent \(6\)-set (both properties are
   inherited by induced subgraphs), so \(G[M]\) is a \((4,6,35)\)-graph, and
   \(\sigma|_M\) is an automorphism of it without fixed points, of type \(5^7\)
   or \(7^5\). Hence excluding those two fixed-point-free types on \(35\)
   vertices kills all eight survivors at once. The contribution does not claim
   the converse, and none holds: a \((4,6,35)\)-graph with such an automorphism
   need not extend to \(n > 35\).
5. **The catalog remark** (`catalog_aut.py`, `catalog_aut.out`). With my own
   graph6 decoder and networkx's automorphism search over Exoo's file: \(37\)
   graphs on \(35\) vertices, all \(K_4\)-free, with
   \(|\mathrm{Aut}| = 1\) for \(21\), \(2\) for \(15\) and \(4\) for one — so no
   known \((4,6,35)\)-graph has an automorphism of order \(5\) or \(7\), exactly
   as claimed.
6. **symC, the new symmetry break** (`symc_check.py`, `symc_check.out`). For
   \(\Phi_\tau\) fixing \(F\) pointwise and sending the \(i\)-th vertex of cycle
   \(j\) to the \(i\)-th vertex of cycle \(\tau(j)\), I checked with my own code
   over **all** \(\tau \in S_k\), for \(1^0 3^3\), \(1^2 3^3\), \(1^3 3^2\) and
   \(1^1 5^2\), that \(\Phi_\tau \sigma \Phi_\tau^{-1} = \sigma\), that the
   induced permutation of the orbit variables maps my \((4,6)\) clause set onto
   itself, and that it carries the internal orbit of cycle \(j\) at difference
   \(d\) to the internal orbit of cycle \(\tau(j)\) at the **same** \(d\). Then,
   exhaustively over all \(\sigma\)-invariant graphs of those four shapes
   (\(4096 + 524\,288 + 16\,384 + 2048\) graphs), every graph has a \(\Phi_\tau\)
   image with sorted internal codes, so imposing
   $$c_0 \le_{\mathrm{lex}} c_1 \le_{\mathrm{lex}} \dots \le_{\mathrm{lex}} c_{k-1}$$
   loses no isomorphism class.
7. **The interaction between symC and symF.** `build()` can emit both blocks at
   once, and the reproduction line for the two \(35\)-vertex instances passes
   `--symf --symc` (there \(f = 0\), so symF is vacuous and the question does not
   arise). For \(f > 0\) the two breaks are simultaneously satisfiable, but only
   in one order: a cycle permutation moves the symF columns \(c_j = f + jp\),
   while a fixed-vertex permutation leaves the cycles alone. So one must sort the
   cycles first and permute the fixed vertices second. I verified this
   exhaustively in the same runs: over all \(\sigma\)-invariant graphs of the four
   shapes, every graph has an image satisfying sorted codes **and** the symF rows
   under exactly that order, with \(0\) exceptions. The source does not state the
   order; it should, before the two are used together with \(f > 0\).
